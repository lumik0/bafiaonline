# Bafia Online

Бафия онлайн - это неофициальная браузерная версия игры «Мафия Онлайн», которая добавляет в игру дополнительный функционал и модификации

в игру можно играть как с компьютера, так и с телефона (айфон поддерживается)

## Запуск

- **Новая бета** (много нововведений, возможны баги): [play.html](https://lumik0.github.io/bafiaonline/play.html)
- **Стабильная старая версия**: [run/index.html](https://lumik0.github.io/bafiaonline/run/index.html)

Локально: скачай архив, распакуй его и открой `play.html` (или `run/index.html` для старой версии) - сервер не нужен

## О новой версии

Новая версия (бета) **полностью переписана с помощью ИИ**: так получилось быстрее, чем писать всё вручную. Протокол, хранилище, экраны, оформление и система модов покрыты тестами (`bun run test`), а результат проверялся в браузере. Нашел баг - напиши пж (контакты ниже)

## Моды

Мод - файл, который игра запускает в изолированном Web Worker: он не видит токен аккаунта и делает только то, что разрешил игрок. Установка: Настройки → Моды → Установить → файл `*.bafiamod.json`

Как создать мод, список разрешений, API, хеши и обновления - в **[mods/README.md](https://github.com/lumik0/bafiaonline/blob/master/mods/README.md)**

## Сборка и разработка

Нужен только [bun](https://bun.sh) (node.js и pnpm не нужны). После установки открой терминал в папке проекта:

```bash
bun install
bun run dev      # локальный сервер с hot reload: http://localhost:8080
bun check        # проверка типов
bun run build    # сборка сайта в dist/ (play.html - новая версия, run/ - старая)
bun buildmod <папка>   # сборка мода в файл .bafiamod.json
```

Чтобы поиграть из собранного: после `bun run build` открой `dist/play.html`

Устройство проекта:

- `common/` - общий код: протокол сервера, сеть, хранилище, оформление, ассеты
- `game/` - сама игра
- `launcher/` - окна, док и лаунчер
- `mods/` - система модов: Web Worker, разрешения, SDK и пример ([описание](mods/README.md))
- `legacy/` - исходники старой версии (`run/`)
