# Моды

Мод - один JS-файл, который игра запускает в **Web Worker**. У воркера нет доступа к DOM, токену аккаунта, сети и хранилищам браузера:
всё, что он может, - это вызовы объекта `mod`: `import { mod } from "bafia:api"` (типы - [sdk/bafia.d.ts](sdk/bafia.d.ts)).

Каждый вызов проходит проверку на стороне игры:

- метод или событие требует **разрешение**, оно должно быть в манифесте и не отключено игроком;
- аргументы проверяются по форме и размеру;
- больше 100 вызовов в секунду - мод останавливается;
- сеть - только `https` и только домены из манифеста;
- токен не получает никто: в событии `packet` нет ответа на вход

> Воркер дополнительно закрывается от `fetch`, `WebSocket`, `indexedDB` и т. п., но это вторая линия защиты. Главная - проверка разрешений в игре

## Формат

Папка мода:

```
manifest.json   id, name, version, permissions, domains (для network)
index.ts        код (можно index.js); несколько файлов и импорты между ними работают
tsconfig.json   чтобы редактор знал типы: "include": ["index.ts", "<путь к>/sdk/bafia.d.ts"]
```

```ts
import { mod } from "bafia:api";

mod.commands.register("hi", args => mod.chat.send(`Привет, ${args.join(" ")}!`));
```

`bun buildmod <папка>` собирает всё в один файл `<id>.bafiamod.json` (`{ manifest, code, sources }`) - его игрок ставит в Настройки → Моды → Установить. В `sources` кладутся твои исходники (`.ts`/`.js` из папки мода), чтобы игрок мог прочитать их в окне «Код». Игра не проверяет, что исходники соответствуют собранному коду, поэтому выполняется и считается только `code`.
Пример - [examples/hello](examples/hello): команда `/hi`, счётчик сообщений, смена темы и четыре кнопки, которые показывают уведомления (`mod.notify`) разных видов.

## Что можно узнать об игре

```ts
import { mod } from "bafia:api";

// какой экран открыт (game:read) - и событие при каждом переходе
await mod.screen.current();                       // "room", "menu", "rooms"…
mod.on("screen:change", ({ name }) => { /* … */ });

// всё о комнате (game:read): этап, роли, кто что может; null - ты не в комнате
const room = await mod.room.state();
room?.phase;          // "registration" | "preparation" | "game" | "finished"
room?.time;           // "night" | "day"
room?.part;           // 1 | 2 - порядок: 1 ночь, 2 ночь, 1 день, 2 день
room?.step;           // те же четыре этапа: "lover" | "night" | "bodyguard" | "vote"
room?.me?.roleName;   // "Шериф"
room?.players;        // [{ index, username, alive, role?, mafia?, votes, action? }]
mod.on("room:state", room => { /* то же самое при любом изменении, в том числе таймера */ });

// действия (room:act) - игра сама отклонит то, что сейчас нельзя
await mod.room.act(2);     // action: ход по твоей роли и времени суток: убить, вылечить, проверить…
await mod.room.vote(2);    // голосование днём
await mod.room.giveUp();
await mod.room.voteKick(true);
```

- **Кто мафия, кто шериф.** В `players[].role` и `players[].mafia` попадает только то, что известно тебе самому: твоя роль, роли союзников по команде, раскрытые в конце игры, результаты твоих проверок. Чужие роли сервер не присылает, мод их узнать не может.
- **Что можно сделать.** У игрока `action` показывает ход, доступный тебе прямо сейчас (`kill` - убить или проголосовать, `check`, `heal`…). Нет `action` - ходить на него нельзя. `act` и `vote` повторяют эту проверку: недоступный ход мод отправить не может.
- Полный список и типы - в [sdk/bafia.d.ts](sdk/bafia.d.ts).

Пример: днём проголосовать за игрока, про которого тебе известно, что он маф (например, ты шериф и проверил его):

```ts
mod.on("room:state", async room => {
  if(room.step != "vote" || !room.me?.alive) return;
  const target = room.players.find(player => player.action == "kill" && player.mafia === true);
  if(target) await mod.room.vote(target.index);
});
```

## Уведомления

```ts
// notify: баннер в углу экрана, как в macOS; сам исчезает через несколько секунд, нажатие убирает
await mod.notify("Игра началась");
await mod.notify("Тебя выбрали мафией", { title: "Роль", kind: "warning" });   // kind: info | success | warning | error
```

Источником в баннере подписано имя мода. Диалог с текстом, который нужно закрыть, - `mod.ui.dialog` (разрешение `ui:dialog`).

## Меню, профиль, комнаты

```ts
import { mod } from "bafia:api";

// пункты в меню по правому клику (ui:menu): "room" - комната в списке, "player" - игрок за столом
mod.menu.add("room", {
  items: room => [{ id: "copy", label: "Скопировать id комнаты" }],
  select: (id, room) => { if(id == "copy") mod.clipboard.write(room.id); }   // clipboard
});

// строки в профиле игрока (ui:profile + profile:read); button - кнопка справа от значения
mod.profile.section({
  rows: profile => [{ label: "Игр", value: profile.playedGames, button: { id: "info", text: "?" } }],
  action: (id, profile) => mod.ui.dialog({ title: "Игры", text: "Сыграно: " + profile.playedGames })   // ui:dialog
});

await mod.rooms.enter("roomId");          // rooms:join - как нажатие на комнату: спросит пароль
await mod.rooms.waitAndJoin("roomId");    // зайти, когда освободится место
```

Игра спрашивает у мода пункты меню каждый раз, когда меню открывается. Если мод отвечает дольше полусекунды или падает, его пунктов просто нет.

## Официальный мод

В игре есть встроенный мод `bafia` ([official](official)): он у каждого игрока, при первой установке включён со всеми разрешениями. Выключить его и отдельные разрешения можно, удалить нельзя. Он работает через то же API, что и любой мод, и показывает, как всё это использовать:

- меню комнаты в списке: «Зайти», «Зайти, когда будет N игроков», «Скопировать id комнаты»;
- расширенная статистика в профиле: игры за мафию и за мирных, всего побед с кнопкой винрейта, M/M, player object id;
- авто-клик: пункт в меню игрока за столом, ход на него делается сам, как только он станет доступен (один раз за этап).

При обновлении игры код официального мода обновляется сам, твои настройки (включён ли, какие разрешения выключены) сохраняются, новые разрешения включаются.

## Библиотеки

Отдельной системы зависимостей нет и не будет: `bun scripts/pack-mod.ts` вшивает в файл мода всё, что ты импортируешь, - npm-пакеты и свои файлы.

```bash
bun add marked          # в папке мода
```

```ts
import { marked } from "marked";
import { shout } from "./util";   // общий код своих модов - просто общая папка
```

- В игре моду ничего не скачивается: тот код, который игрок подтвердил и чей хеш видит, и есть весь код.
- Лимит файла мода - 5 МБ. Тяжёлые библиотеки (и всё, что тянет Node-модули вроде `fs`, `net`, `http`) не подойдут: в воркере их нет.
- Загрузка кода по URL (`import("https://…")`) не работает: сеть из воркера закрыта, а `net.fetch` отдаёт только текст.
- Моды друг от друга не зависят и друг друга не вызывают.

## Разрешения

| Риск | Разрешение | Что даёт |
|---|---|---|
| критично | `packet:read` | видеть все пакеты от сервера |
| критично | `packet:send`, `shop:spend`, `account:act` | заявлены, API пока нет |
| высокий | `chat:send` | писать в общий чат и чат комнаты |
| высокий | `room:act` | ходить и голосовать |
| высокий | `network` | запросы к доменам из манифеста |
| высокий | `rooms:join` | заходить в комнаты |
| высокий | `friends:write` | заявлено, API пока нет |
| средний | `chat:read`, `room:read`, `game:read`, `account:read` | читать чат, ники игроков комнаты, этапы игры, роли (только известные игроку), текущий экран, ник и уровень |
| средний | `chat:private:read`, `friends:read` | заявлены, API пока нет |
| средний | `profile:read` | статистика профилей игроков |
| низкий | `ui:panel`, `ui:menu`, `ui:profile`, `ui:dialog`, `theme`, `storage`, `notify`, `commands`, `clipboard` | панель, пункты меню, строки профиля, окна с текстом, цвета, своё хранилище, уведомления, команды, буфер обмена |
| низкий | `ui:overlay`, `sound` | заявлены, API пока нет |

Игрок видит разрешения при установке и может отключить любое (кнопка «Разрешения» у мода). При обновлении мода новые разрешения остаются выключенными, пока игрок их не включит

## Обновления и хеши

Если в `manifest.json` есть `"updateUrl": "https://example.com/my-mod/update.json"`, игра сама (не чаще раза в час, и по кнопке "Обновления") спрашивает по этому адресу, нет ли новой версии. Описание версии - JSON, его пишет `bun scripts/pack-mod.ts` рядом с файлом мода (`<id>.update.json`):

```json
{ "version": "1.1.0", "file": "my-mod.bafiamod.json", "sha256": "…", "sha1": "…" }
```

Правила, которые проверяет игра:

- адрес только `https`, без перенаправлений и без cookie;
- файл обновления лежит на том же сайте, что и описание;
- обязателен хеш файла (SHA-256 и/или SHA-1; если указаны оба, совпасть должны оба);
- это тот же мод (`id`), версия в файле равна заявленной, `updateUrl` обновлением не меняется;
- ничего не ставится само: игрок видит «Доступна версия X», нажимает «Обновить» и подтверждает; **новые разрешения остаются выключенными**, пока он их не включит.

В окне «Код» у каждого мода показан SHA-256 его кода (там же поиск и приложенные исходники) - его можно сверить с опубликованным автором

Тебе как автору в `mod` доступно `mod.permissions.has("chat:send")` - узнать, включил ли игрок разрешение, до вызова

## Устройство

- [permissions.ts](permissions.ts) - таблица разрешений, какой метод/событие какое требует
- [manifest.ts](manifest.ts) - разбор и проверка манифеста и файла мода
- [runtime.ts](runtime.ts) - код внутри воркера (объект `mod`)
- [host.ts](host.ts) - `ModRuntime`: проверка каждого сообщения из воркера, лимиты, события
- `game/mods/manager.ts` - установка, хранение (`/mods/installed.json`), запуск, связь с комнатой и чатом
